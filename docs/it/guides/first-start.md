# Primo avvio

1. **Collega** la tua macchina HLLM alla corrente e alla rete di casa.
2. **Installa l'app HLLM** sul telefono e inquadra il codice mostrato dalla macchina.
3. **Saluta.** HLLM si presenta e ti fa qualche domanda per conoscerti: il tuo nome, la tua lingua, in cosa vorresti aiuto.
4. **Fatto.** Da adesso HLLM ricorda. Stanotte dormirà per la prima volta.
