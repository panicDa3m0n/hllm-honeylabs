# Scegli una personalità (Unlocked)

Disponibile sulle macchine di tua proprietà.

1. Nell'app apri **Mente → Personalità**.
2. Descrivi chi vuoi: «un allenatore severo ma giusto che mi chiama per cognome».
3. Imposta il **tono** e le **regole**: argomenti, schiettezza, lingua.
4. Provala, correggila, salvala. Puoi tenere più personalità e passare dall'una all'altra.
