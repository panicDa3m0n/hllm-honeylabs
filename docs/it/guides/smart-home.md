# La tua casa smart

1. Nell'app apri **Casa → Aggiungi dispositivi**: HLLM OS trova i dispositivi compatibili nella tua rete.
2. Dai un nome a stanze e dispositivi, oppure dillo a HLLM: «la lampada vicino al divano è la luce per leggere».
3. Chiedi a parole: «abbassa la luce per leggere alle 22:00 ogni sera».
