# Updates & licensing

- **No subscription for the model.** Buy the machine and the mind is yours.
- **5 years of security updates** included with every purchased machine.
- **New models.** Some new models may need a newer machine, because a bigger mind needs more hardware. Many new models will also run on machines you already own: we limit compatibility only for technical and safety reasons, never for commercial ones.
- **Subscriptions** always run the latest Standard model available for that machine.
