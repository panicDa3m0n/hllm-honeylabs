# First start

1. **Plug in** your HLLM machine and connect it to your home network.
2. **Install the HLLM app** on your phone and scan the code shown by the machine.
3. **Say hello.** HLLM introduces itself and asks a few questions to get to know you: your name, your language, what you'd like help with.
4. **Done.** From now on HLLM remembers. Tonight it will sleep for the first time.
